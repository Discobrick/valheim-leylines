# Changelog

## 0.5.0

- The ritual has a secret name. Each portal built in a circle makes the stones whisper one of its runes, and everyone nearby hears it. Only that name moves the ley lines; any other does nothing. The name changes with every shift, and the stones stay silent while the ley lines recover. This replaces the "never the same name twice" rule.

## 0.4.1

- Renamed to **Ancient Ley Lines** (Thunderstore package `Ancient_Ley_Lines`); another mod already uses the name Ley Lines.
- `MaxPortals` is limited to 1–5.
- `CircleLocations` is no longer a config option; portals are only in stone circles.
- Config and README: clearer notes on `LeaveEntrance`, a `StoneHenge` example for `TargetLocations`, and a caution for the band settings.

## 0.4.0

- First public release as **Ley Lines**.
- Portals open once you've set foot in their destination's biome (`OpenByBiome`; off = the destination must be explored on the map).
- Dolmen gates open both ways as soon as the circle portal leading to them is open.
- Ashlands and Deep North portals ask for confirmation instead of opening when you walk in.
- Every gap between the stones gets a portal (`LeaveEntrance` to keep one gap free).
- All portals in a circle sit level, at the height of the highest ground under them.
- Lore-flavoured portal descriptions instead of location names and distances.
- Default return key is now G.
